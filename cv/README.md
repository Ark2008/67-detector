# CV

Python-модуль для распознавания жеста Six-seven по внешним координатам.

Ответственный разработчик: Никита

- `hand_tracking/` — резерв для отдельного трекера; распознаватель его не вызывает.
- `gesture_detector/` — определение жеста по данным отслеживания.
- `tests/` — тесты pytest.

## Вызов из backend (Python 3.10+)

```python
from cv.gesture_detector import detect_gesture

result = detect_gesture(frames)
if result["gesture"] == "six_seven":
    pass  # backend проверяет cooldown и начисляет очко
```

`frames` — список последних сообщений `frame` из `docs/websocket.md`,
строго по возрастанию `timestamp_ms`. Возвращается `{"gesture": "six_seven"}`
или `{"gesture": "none"}`. Рекомендуемое начальное окно — 2 секунды при
15–20 FPS. Нужны минимум 12 наблюдений и 0.7 секунды движения.
Адаптер переводит миллисекунды в секунды; вход не меняется, состояние между
вызовами не сохраняется. Backend хранит отдельное окно для каждой сессии.
Неверная структура вызывает `ValueError` (backend: `invalid_payload`).
Пустое окно или отсутствие жеста — `none`. Оценивается последний кадр с историей,
а не наличие положительного результата когда-либо в окне.

Алгоритм прототипа сохранён: центры ладоней, амплитуда, отрицательная корреляция
движений и устойчивые смены взаимного положения рук. Руки сортируются по x;
перекрещивание рук остаётся ограничением алгоритма. Короткая потеря трекинга
допускается до 0.45 секунды, но на кадре без двух надёжных рук жест не выдаётся.
`score < 0.5` трактуется адаптером как потеря трекинга. Длинный разрыв очищает историю.

## Ориентация ладоней

Стандартный режим `palm_check="off"` проверяет движение, но **не проверяет
направление ладоней и раскрытие пальцев**: обязательный контракт репо содержит
только нормализованные landmarks.

Для строгой проверки из v4 каждой руке нужно дополнительное поле
`world_landmarks`: 21 объект `{x, y, z}` в мировых координатах MediaPipe,
соответствующих `handedness` и `landmarks` этой же руки.
Передачу поля необходимо согласовать с источником координат и backend.
Нормализованные точки не заменяют мировые.

```python
from cv.gesture_detector import DetectorConfig, detect_gesture
result = detect_gesture(frames, config=DetectorConfig(palm_check="up"))
```

Если мировых точек нет, строгий режим возвращает `none`, не отключая проверку.
Для калибровки зеркалирования сохранён параметр `palm_normal_sign=-1`.

## Потоковый API

Сохранены `Gesture67Detector`, `DetectorConfig`, `DetectionResult`.
`update(hands, timestamp_s, world_hands=..., handedness=...)` принимает **секунды**.
Для каждого потока нужен отдельный экземпляр; `reset()` начинает новую последовательность.
Положительные результаты могут повторяться на соседних кадрах: это классификация,
а не событие начисления очка. `cooldown_s` удалён; cooldown принадлежит backend.
Камера, MediaPipe, модель, webcam demo и `.venv` не входят в распознаватель.

## Проверка

Из корня репозитория:

```bash
python -m pip install -r cv/requirements.txt
python -m pytest cv/tests -q
```

У ядра и адаптера нет внешних зависимостей; pytest нужен только для тестов.
Тесты синтетические. Точность на реальных пользователях и ракурсах требует
проверки на записях настоящего трекера и настройки порогов.

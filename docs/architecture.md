# Архитектура

```text
Камера браузера → Frontend ⇄ WebSocket ⇄ Backend → CV
                                    │
                                    └── PostgreSQL
```

Frontend показывает игру, получает доступ к камере и отображает ответы. Источник координат извлекает landmarks и передаёт их через backend. Backend принимает сообщения, вызывает CV, отвечает за игровую логику и хранение результатов. CV определяет жест по полученным координатам и не обращается к камере. PostgreSQL предназначен для результатов и рейтинга.

Frontend не обращается к CV или базе напрямую. CV не начисляет очки и не хранит результаты.

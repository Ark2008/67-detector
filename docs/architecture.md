# Архитектура

```text
Камера браузера → Frontend ⇄ WebSocket ⇄ Backend → CV
                                    │
                                    └── PostgreSQL
```

Frontend показывает игру, получает доступ к камере и отображает ответы. Backend принимает сообщения, вызывает CV, отвечает за игровую логику и хранение результатов. CV отслеживает руку и определяет жест. PostgreSQL предназначен для результатов и рейтинга.

Frontend не обращается к CV или базе напрямую. CV не начисляет очки и не хранит результаты.

# WebSocket: предварительная спецификация

Планируется двустороннее соединение браузера с backend на время игры. Endpoint пока не реализован.

| Направление | Назначение |
| --- | --- |
| Клиент → сервер | Данные для распознавания жеста |
| Сервер → клиент | Результат распознавания и состояние игры |
| Сервер → клиент | Ошибка обработки |

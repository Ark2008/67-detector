# Six-seven

Браузерная игра: камера помогает распознать жест Six-seven, после чего игрок получает очки и может посмотреть рейтинг. 

## Модули

- [frontend](frontend/README.md) — React, TypeScript, Vite.
- [backend](backend/README.md) — FastAPI, WebSocket и доступ к данным.
- [cv](cv/README.md) — распознавание жеста по координатам от внешнего трекера.
- [docs](docs/README.md) — общие решения и правила.

Стек проекта: PostgreSQL, Docker Compose, pytest и Playwright в дополнение к технологиям модулей. Инструкции по запуску — в [docs/development.md](docs/development.md).

# Frontend

Интерфейс игры на React, TypeScript и Vite. Здесь появятся экран игры, работа с камерой, WebSocket и рейтинг.

Ответственный разработчик: Эля

- `src/components/` — элементы интерфейса.
- `src/pages/` — страницы.
- `src/hooks/` — React-хуки.
- `src/services/` — взаимодействие с API.
- `src/mocks/` — временные данные для независимой разработки.
- `public/` — статические файлы.

Сейчас приложение показывает заглушку. Команды: `npm install`, `npm run dev`, `npm run build`.
